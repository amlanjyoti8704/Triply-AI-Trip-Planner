# Triply — AI Trip Planner

A full-stack, multi-agent AI travel planning system. Four specialized AI agents collaborate in real-time to search flights, discover hotels, craft itineraries, and deliver polished travel plans.

![Architecture](https://img.shields.io/badge/Architecture-React%20%7C%20Express%20%7C%20FastAPI%20%7C%20LangGraph-blue?style=for-the-badge)

---

## Architecture

```
┌─────────────┐     ┌──────────────┐     ┌──────────────────┐     ┌────────────┐
│  React App  │────▶│  Express.js  │────▶│  FastAPI (Python) │────▶│ PostgreSQL │
│  Port 5173  │ SSE │  Port 3001   │ SSE │  Port 8000        │     │  Memory DB │
└─────────────┘     └──────────────┘     └──────────────────┘     └────────────┘
                                                │
                                    ┌───────────┼───────────┐
                                    ▼           ▼           ▼
                              Flight Agent  Hotel Agent  Itinerary Agent
                             (AviationStack) (Tavily)    (Groq LLM)
                                                           │
                                                           ▼
                                                      Final Agent
                                                      (Groq LLM)
```

| Layer | Technology | Purpose |
|-------|-----------|---------|
| **Frontend** | React + Vite + Tailwind CSS v4 | Premium dark-mode UI with real-time streaming |
| **API Gateway** | Express.js | CORS, routing, SSE proxy to AI service |
| **AI Service** | FastAPI + LangGraph | Multi-agent pipeline with SSE streaming |
| **LLM** | Groq (LLaMA 3.3 70B) | Itinerary generation and final plan synthesis |
| **Memory** | PostgreSQL | Conversation persistence via LangGraph checkpointer |
| **APIs** | AviationStack, Tavily | Flight search and hotel/web search |

---

## Features

- ✈️ **Flight Search** — Real-time flight data from AviationStack
- 🏨 **Hotel Discovery** — Web search via Tavily for hotel recommendations
- 🗓️ **Smart Itineraries** — Day-by-day plans generated by LLaMA 3.3 70B
- 🧠 **Final Compilation** — Polished travel plan combining all agent outputs
- 📡 **Live Streaming** — SSE-based real-time agent status updates in the browser
- 💾 **Memory** — Conversation history persisted in PostgreSQL
- 📱 **Responsive** — Works beautifully on desktop and mobile
- ⬇️ **Download** — Export your travel plan as Markdown

## Setup

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd Triply-AI-Trip-Planner
```

### 2. Create the PostgreSQL database

```sql
CREATE DATABASE langgraph_memory_demo;
```

### 3. Set up environment variables

```bash
cp .env.example .env
```

Edit `.env` and fill in your API keys:

```env
GROQ_API_KEY=your_groq_api_key
TAVILY_API_KEY=your_tavily_api_key
AVIATIONSTACK_API_KEY=your_aviationstack_api_key
DATABASE_URL=postgresql://postgres:your_password@localhost:5432/langgraph_memory_demo
```

### 4. Get API Keys

| Service | URL |
|---------|-----|
| Groq | https://console.groq.com |
| Tavily | https://tavily.com |
| AviationStack | https://aviationstack.com |

### 5. Install dependencies

**AI Service (Python):**
```bash
cd ai-service
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

**Express Backend (Node.js):**
```bash
cd server
npm install
```

**React Frontend:**
```bash
cd client
npm install
```

## Running the App

Start all three services (each in a separate terminal):

**Terminal 1 — AI Service (FastAPI):**
```bash
cd ai-service
source venv/bin/activate
python app.py
# Runs on http://localhost:8000
```

**Terminal 2 — Express Backend:**
```bash
cd server
npm run dev
# Runs on http://localhost:3001
```

**Terminal 3 — React Frontend:**
```bash
cd client
npm run dev
# Runs on http://localhost:5173
```

Open **http://localhost:5173** in your browser.

## How It Works

1. **You describe your trip** in the React frontend
2. **React** sends the query to Express via `POST /api/travel/plan`
3. **Express** proxies the request to FastAPI as an SSE stream
4. **FastAPI** runs the LangGraph pipeline:
   - 🔍 **Flight Agent** searches AviationStack for flights
   - 🏨 **Hotel Agent** searches Tavily for hotel recommendations
   - 🗓️ **Itinerary Agent** generates a day-by-day plan using Groq LLM
   - 🧠 **Final Agent** compiles everything into a polished travel plan
5. **Each agent** emits an SSE event when it completes
6. **React** renders live status updates with animated cards
7. **PostgreSQL** stores the conversation for future reference
